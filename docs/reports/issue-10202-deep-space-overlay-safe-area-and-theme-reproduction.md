# #10202 深空二级页面顶部安全区、标题居中与背景色复现记录

## 复现环境

- 本文记录本地工作区对 #10202 的复现与验证；本次先提交文档，文中提及的源码修改尚未作为本次文档提交的一部分。
- Expo SDK 54，iOS 模拟器，开发包 `com.wificamera.development`；使用 `agent-device` 检查实际画面。
- 入口：底部「深空」Tab → 左上角「菜单」。
- 本记录针对深空浮层；首页、设置 Tab 已有自己的安全区布局，不在本次全局增加顶部间距。

## 原始问题及复现步骤

1. 在深空菜单中依次打开「设置」→「高级的」及「所在位置」，观察顶部标题、状态栏下方空隙和面板背景。原先部分二级面板的内容没有为设备顶部安全区留出空间，「设置」标题相对屏幕水平中心偏移；深空浮层灰色背景与应用深色主题背景不一致。
2. 返回菜单，打开「观测工具」及其子页、「日历」，检查页头是否落入状态栏区域、左右按钮是否令标题偏移，以及底色是否一致。
3. 打开「星空述语」，进入任一文化详情，检查列表和详情页头、顶部安全区及详情卡背景。此前这些页面使用各自的灰色背景，而非共用深空主题背景。
4. 在有顶部刘海/状态栏的设备上对照观察；固定数值不能代替实际 `insets.top`。仅在已经处理安全区的页面外再统一包一层 padding 会产生双重留白。

## 原因与修复

- 根布局已经有 `SafeAreaProvider`，但深空内的 Modal、抽屉和从顶部展开的面板不一定继承路由页面的安全区；分别在尚未处理的容器使用 `useSafeAreaInsets().top`。
- `FeatureSheet` 标题使用 `flex: 1` 并居中；只有右侧关闭按钮而左侧缺少同宽占位时，标题的中心落在剩余空间中心，不是屏幕中心。左右各保留一个 `featureClose` 宽度：左边没有返回按钮时使用占位，右边隐藏关闭按钮时也使用占位。
- 深色浮层以 `src/features/deep-space/ui/deep-space-theme.ts` 的 `OVERLAY.drawer` / `drawerHeader` / `card` 为共用背景色，改为与应用深色背景一致的 `#0A0A0A`；日历、星空述语、位置弹窗和面板复用主题色。浅色主题仍使用自己的配色。强调色 `accent` 未改动。
- 没有在整个应用或深空路由统一叠加安全区，以免已有安全区处理的页面出现两份顶部留白。

## 验证步骤与结果

- iOS 模拟器打开「设置」「高级的」「所在位置」，顶部标题可见且水平居中，背景不再是原来的灰色；「星空述语」列表及文化详情也已通过 `agent-device` 截图目视检查。
- 深空屏幕测试：`./node_modules/.bin/jest --runInBand src/features/deep-space/deep-space-map-screen.test.tsx`，**100/100 通过**，包含设置面板安全区和背景色断言。
- `./node_modules/.bin/tsc --noEmit` 与 `git diff --check` 通过。
- **已知检查限制**：项目原有 ESLint `max-lines-per-function` 规则在当前工作区修改文件上报 13 处超长函数；临时用 `--rule 'max-lines-per-function: off'` 覆盖后其余规则通过。这是当前未提交源码的检查结果，不能将其记为按项目原规则 lint 通过，也不代表本次文档提交包含了这些修复。

## 回归检查清单

- 深空菜单、设置、高级的、所在位置、观测工具、日历、星空述语列表及详情均不被状态栏遮挡。
- 有／没有左侧返回按钮、显示／隐藏右侧关闭按钮时标题都位于屏幕水平中心。
- 深色面板背景与主题一致；浅色模式和底部 Tab 栏未产生额外留白或改色。
