RA/Dec 坐标推送链路（逐帧跟踪）

步骤位置操作延迟
1相机 Linuxastrometry.net 盲解 → RA/Dec (7-10s/次)
或 ICM-42688-P 陀螺仪融合 → RA/Dec (≥10Hz)		—
2CameraService.tsTCP 接收 → 解析协议 → 更新 CameraContext<1ms
3StellariumOverlay.tsxuseEffect 检测 currentRaDec 变化 → stellaRef.gotoRaDec()React render tick
4StellariumView.tsxuseImperativeHandle → send({type:'goto_radec', ra, dec})<1ms
5WebView BridgewebViewRef.postMessage(JSON.stringify(msg))~0.1ms
6HTML 壳window.addEventListener('message') → stel.lookAt(pos, 0.5)<1ms
7Stellarium Engine四元数 slerp 平滑动画 + WebGL 渲染1 frame (16ms)
端到端延迟（不含解析）< 20ms

关键数据格式

// RN → WebView (postMessage via JSON) { "type": "goto_radec", "ra": 1.533, "dec": -0.089, "duration": 0.5 } { "type": "zoom_to", "fov": 2.5, "duration": 0.3 } { "type": "search_target", "name": "M42" } { "type": "toggle_constellations", "visible": true } // WebView → RN { "type": "engine_ready" } { "type": "view_state", "fov": 1.047 } { "type": "context_lost" } { "type": "error", "message": "..." }
👆 触控通路分析 无损适配

问题根因：canvas.js L106 — touchstart 用了 passive:true

// stellarium-web-engine/src/js/canvas.js — 当前源码 canvas.addEventListener('touchstart', function(e) { // ❌ 没有 e.preventDefault()！ for (var i = 0; i < e.changedTouches.length; i++) { var id = e.changedTouches[i].identifier; Module._core_on_mouse(id, 1, relX, relY, 1); } }, {passive: true}); // ← iOS WKWebView 下浏览器仍会滚动/缩放

需要的修改（3处，共5行）

// 修改1: canvas.js L98-106 — touchstart canvas.addEventListener('touchstart', function(e) { e.preventDefault(); // ← 新增：阻止浏览器默认手势 for (...) { ... } }, {passive: false}); // ← 改为 false // 修改2: canvas.js L117 — touchend canvas.addEventListener('touchend', function(e) { e.preventDefault(); for (...) { ... } }, {passive: false}); // ← 显式声明 // 修改3: HTML 壳 CSS canvas { touch-action: none; } html,body { overscroll-behavior: none; overflow: hidden; position: fixed; }

RN WebView 配置

<WebView scrollEnabled={false} // 禁止 WebView 滚动 bounces={false} // iOS：禁止回弹 overScrollMode="never" // Android：禁止过度滚动 allowsBackForwardNavigationGestures={false} // iOS：禁止滑动返回 setBuiltInZoomControls={false} // Android：禁止内置缩放 androidLayerType="hardware" // 强制硬件加速 />

触摸流转

👆 手指触摸 WebView
├─ RN Overlay View onStartShouldSetResponder → true
├─ 触摸传到 WebView 内
├─ canvas touchstart {passive:false}
